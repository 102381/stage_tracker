# Stage hours

A small page for keeping track of internship hours. You pick your first day, enter the hours you already have, then add each day you work. It shows when you will finish compared to the last day (5 Feb 2027) and how far you are from the 620 hours.

Live: https://102381.github.io/stage_tracker/

Everything is stored in your own browser and nothing is sent anywhere. To move to another phone or laptop, use Backup in Settings.

To run it locally, open `index.html`. There is no build step. The 620 hours and the dates are set near the top of `app.js`.
